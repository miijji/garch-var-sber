# Данные исследования

Основной источник первой версии — [MOEX ISS](https://iss.moex.com/iss/reference/), SBER, режим TQBR, дневные свечи (`interval=24`). Запрошенный период: 2016-01-01 — 2025-12-31.

В `raw/` сохраняются:

- `SBER_2016-01-01_2025-12-31.csv` — дата и цена закрытия, отсортированные по дате;
- `SBER_2016-01-01_2025-12-31.provider.json` — исходные ответы ISS по всем непустым страницам;
- `SBER_2016-01-01_2025-12-31.metadata.json` — URL запросов, время получения UTC, поля, единицы, преобразования, отчёт качества и SHA-256 обоих файлов.

Найдено 2577 цен с 2016-01-04 по 2025-12-30. Пропусков цен и повторных дат нет. Перерыв до 2022-03-24 составляет 27 календарных дней; он сохранён без заполнения. Экстремальные доходности не удаляются. Цены в рублях, не скорректированы на дивиденды и корпоративные события.

Это зафиксированный исторический снимок. Для повторного получения выполните `python scripts/download_data.py` через окружение проекта, либо запустите ноутбук. Если файлы присутствуют, загрузчик проверяет их контрольные суммы и использует кэш. Повреждённые и неполные снимки автоматически не заменяются.

Снимки локальны и исключены из Git. Условия источника нужно проверить перед распространением; наличие открытого API не означает разрешения на перепубликацию данных.

Для Kaggle предусмотрен импорт CSV одного актива и дневной частоты. Настройки и пример команды находятся в [README.md](../README.md). Сведения о корректировках нужно брать из описания выбранного набора.
