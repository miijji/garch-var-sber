# Исследование GARCH и VaR

## Цель и требования пользователя

Создать воспроизводимый Jupyter Notebook для прогнозирования дневной волатильности и параметрического VaR на следующий торговый день с проверкой на отложенных данных.

1. Получить дневные цены закрытия акций, например Сбербанка, или индекса Мосбиржи. Предпочтителен Kaggle, если подходящие данные доступны. Рассчитать логарифмические доходности.
2. Проверить стационарность, построить ACF и PACF доходностей и их квадратов для исследования кластеризации волатильности.
3. Использовать библиотеку `arch`, обучить GARCH(1,1), получить прогноз условной дисперсии и волатильности на один день.
4. Рассчитать параметрический VaR на уровне 95% или 99%.
5. Главный раздел — бэктестинг: фактические доходности и границы VaR на графике, число нарушений и сравнение с ожидаемой частотой.
6. Бонус — Expected Shortfall и анализ убытков в дни нарушения VaR.

### VaR и знаки

Пусть `c` — уровень доверия, `alpha = 1 - c`, `Phi` — функция стандартного нормального распределения. Нижняя граница доходности:

`q_(t+1, alpha) = mu_(t+1) + sigma_(t+1) * Phi^(-1)(alpha)`.

Это эквивалентно пользовательской записи `mu - Z_c * sigma`, если `Z_c` — положительный квантиль уровня доверия. Нарушение: `r_(t+1) < q_(t+1, alpha)`. VaR в соглашении об убытке равен `-q`; подписывать границу доходности и показатель убытка раздельно. Не смешивать доли и проценты. Денежный VaR потребует размера позиции и преобразования логарифмических доходностей.

Реализованы оба уровня: 95% и 99%.

### Бэктестинг и ES

- Построить доходности, границы VaR и отметки нарушений.
- Для каждого уровня показать число валидных прогнозов `N`, ожидаемое число нарушений `alpha * N`, фактическое число и частоту.
- Дополнить тестом Купика и тестом независимости Кристофферсена. Обработать нулевые количества переходов и граничные случаи; отметить ограниченную мощность при редких нарушениях.
- Сравнить с историческим VaR, также рассчитанным только по прошлым наблюдениям.
- Бонус: модельный ES. Для нормальной модели нижнее хвостовое среднее: `mu - sigma * phi(Phi^(-1)(alpha)) / alpha`, где `phi` — стандартная нормальная плотность; для убытка знак меняется.
- Отдельно показать среднюю фактическую доходность и убыток в дни нарушения. Это описательная оценка хвостовых потерь, а не полноценный тест ES. Без нарушений среднее не определено; при малом числе оно неустойчиво.
