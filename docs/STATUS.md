# Текущее состояние

Обновлено: 28 октября 2026 года.

## Сделано

Первая рабочая версия исследования завершена. Созданы отдельное окружение `.venv` на Python 3.13.9 из Anaconda, программные модули, выполненный Jupyter Notebook, автоматические тесты и инструкции VS Code.

- [Ноутбук](../outputs/garch_var_research.ipynb): 18 ячеек, все 9 вычислительных ячеек выполнены с чистого ядра.
- [Проверенные результаты](../outputs/RESULTS.md), [отчёт](../outputs/REPORT.md), [таблица бэктеста](../outputs/backtest_summary.csv).
- [Данные](../data/README.md): 2577 цен SBER за 2016-01-04 — 2025-12-30. Полный источник и контрольные суммы сохранены в data/raw/.
- Реализованы EDA, ADF/KPSS, ACF/PACF, ARCH-LM, диагностика остатков, GARCH-normal/t, исторический VaR, тесты покрытия и ES.
- Программный запуск поддерживает MOEX и импорт CSV, в том числе скачанного с Kaggle.

## Результат проверки на 500 наблюдениях

| Модель | Нарушения 95% (ожидается 25) | Нарушения 99% (ожидается 5) |
| --- | --- | --- |
| GARCH-normal | 15 | 6 |
| GARCH-t | 19 | 4 |
| Исторический VaR | 9 | 1 |

На уровне значимости 5% тест Купика отвергает частоту для normal 95% и исторического VaR на обоих уровнях. Для GARCH-t не отвергает на обоих уровнях. Это не доказательство качества; ограничения редких нарушений отмечены в отчёте.

Обучение заканчивается 2024-04-17; даты отложенных наблюдений и все прогнозы доступны в полном запуске `notebook_20261028T192307338868Z` (локальная папка outputs/runs, не публикуется).

## Ограничения и незавершённое

Основная разработка завершена. Ручной просмотр в интерфейсе VS Code ещё не выполнялся; пользователь должен выбрать .venv как ядро по [инструкции](../README.md). Kaggle API не настраивался и авторизованная загрузка с Kaggle не проверялась; реализован импорт скачанного CSV.

Цены не скорректированы на дивиденды. Перерыв торгов в 2022 году сохранён и отмечен; доходность после него охватывает 27 календарных дней. Исторический прогноз после 2025-12-30 не является прогнозом на текущую дату. ES показан с описательной оценкой хвоста, полноценный отдельный тест ES не реализован.
