## Настройки первой версии

Ниже — первоначальные предложения и их основания. Для первой реализации выбраны эти настройки до получения результатов бэктестинга.

| Параметр | Предложение | Основание / условие |
| --- | --- | --- |
| Актив | Акции Сбербанка | Пример пользователя; выбор после оценки источника |
| Период | По возможности 8–10 лет | Разные режимы волатильности; зависит от полноты данных |
| Источник | Сначала Kaggle, запасной вариант — Мосбиржа | Предпочтение пользователя; доступность не проверена |
| Тестовый период | Около 500 последних торговых наблюдений | Начальная настройка; учитывать редкость нарушений на 99% |
| Базовая модель | Постоянное среднее, GARCH(1,1), нормальные ошибки | Прозрачная отправная точка |
| Прогнозирование | Расширяющееся окно, ежедневная переоценка | Последовательная проверка по доступной истории |
| VaR | 95% и 99% | Сравнение частых и редких хвостовых событий |
| Дополнения | Стьюдент, исторический VaR, ES | Проверка хвостов и сравнительного качества |

MOEX ISS проверен реальной загрузкой; пригодность моделей оценена в бэктесте, результаты находятся в outputs/REPORT.md. При изменениях настроек фиксировать причины здесь. Доступ к Kaggle API не настраивался: поддержан импорт скачанного CSV.

## Итоги реализации

- Полный запуск: SBER, 2577 цен, 2576 доходностей; 2076 наблюдений первоначального обучения и 500 проверки. Переоценка GARCH на каждом шаге расширяющегося окна.
- Ошибки сходимости останавливают расчёт, пропуски прогнозов не скрываются. При недостатке состояний переходов тест независимости не определён, сохранён NaN.
- Локальные снимки и результаты отдельных запусков исключены из Git. Итоговый ноутбук, отчёт, таблица и выбранные графики находятся в outputs/. Репозиторий ещё не создавался.
