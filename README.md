# GARCH VaR для акций Сбербанка

Исследование волатильности SBER на дневных данных Мосбиржи за 2016–2025 годы. Сравниваются GARCH(1,1) с нормальными ошибками, GARCH со Стьюдентом и исторический VaR. Для каждой модели рассчитаны VaR 95%/99% и Expected Shortfall.

[Ноутбук с расчётами](outputs/garch_var_research.ipynb) · [Результаты бэктеста](outputs/backtest_summary.csv)

## Методика и результаты

Из 2577 цен получены 2576 логарифмических доходностей. Последние 500 наблюдений оставлены для проверки. На каждом шаге GARCH заново обучается на предыдущей истории и прогнозирует следующее наблюдение.

В ноутбуке: ADF и KPSS, ACF/PACF доходностей и их квадратов, ARCH-LM, диагностика остатков и бэктестинг с тестами Купика и Кристофферсена.

| Модель | Нарушения VaR 95% | Нарушения VaR 99% |
| --- | ---: | ---: |
| Ожидаемое число | 25 | 5 |
| GARCH-normal | 15 | 6 |
| GARCH-t | 19 | 4 |
| Исторический VaR | 9 | 1 |

Тест Купика не отвергает частоту нарушений GARCH-t на обоих уровнях при значимости 5%. На уровне 99% нарушений мало, поэтому выводы требуют осторожности. Меньшее число нарушений само по себе не означает лучшую калибровку.

## Запуск

Проверено на Windows и Python 3.13.9. Из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe -m pip install --no-deps --no-build-isolation -e .
.\.venv\Scripts\python.exe -m ipykernel install --prefix .venv --name garch-var --display-name "Python (GARCH VaR)"
.\.venv\Scripts\python.exe -m jupyterlab outputs/garch_var_research.ipynb
```

В VS Code можно открыть ноутбук и выбрать `.venv` в списке ядер. Период, размер тестовой выборки и импорт CSV настраиваются в начале ноутбука. Котировки загружаются из [MOEX ISS](https://iss.moex.com/iss/reference/) при первом запуске, затем используются из локального кэша.

Расчёт без ноутбука и тесты:

```powershell
.\.venv\Scripts\python.exe -m garch_var
.\.venv\Scripts\python.exe -m pytest -q
```

Параметры запуска доступны через `-m garch_var --help`. Результаты каждого расчёта сохраняются в `outputs/runs/`.

## Ограничения

Цены не скорректированы на дивиденды. Неторговые дни не заполняются: доходность после остановки торгов охватывает весь перерыв. Риск выражен в единицах логарифмической доходности; денежный VaR не рассчитывается. Сопоставление ES с фактическими хвостовыми потерями носит описательный характер.
